# CLAUDE.md

Project rules live in `.aiassistant/rules/` and are shared with the JetBrains AI Assistant and Junie.
Do not duplicate them here – follow these files:

- @.aiassistant/rules/coding-conventions.md – architecture, naming, REST, CDI, logging and testing conventions (always applies).
- @.aiassistant/rules/code-review.md – procedure for code reviews with Jira requirement validation (apply when asked to review a change).

Jira access is provided by the Atlassian MCP server configured in the IntelliJ settings
(*Settings → Tools → AI Assistant → Model Context Protocol (MCP)*), see `docs/ai/README.md`.
